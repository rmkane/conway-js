Rules

What is this?

Conway's Game of Life is a cellular automaton on an infinite grid. Each cell is either alive or dead. Time advances in discrete generations.

B3/S23

  • Birth: a dead cell with exactly 3 live neighbors becomes alive.
  • Survival: a live cell with 2 or 3 live neighbors stays alive.
  • Death: otherwise the cell dies or stays dead (under/overpopulation).

Pattern types

  • Still lifes — stable shapes that never change.
  • Oscillators — cycle through a fixed period.
  • Spaceships — translate across the grid over time.

Controls

Seed drives a deterministic random soup. The same seed always produces the same starting cells. Mode switches board interaction: Spawn shows a pattern ghost and places on click; Inspect highlights the cell under the cursor. Cursor anchor chooses center vs top-left for spawn placement.

Use the footer to play, step, reset to seed, or clear the board. Settings are stored in the URL.
